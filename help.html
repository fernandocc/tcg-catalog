How to use TCG Catalog

Everything happens in this browser window — no commands to type.

Install the card data (first time only)

The app installs it by itself the first time it opens (a progress bar shows on the Home page for a few seconds). Later, use Check for new sets on Home when a new expansion comes out (needs internet).

Set up the camera

  • Put the phone above the card slinger, camera pointing down, so the whole dark well is in view with a little margin around it.
  • Use a dark, matte background and soft light from the sides — reflections make cards harder to read.
  • Keep the phone plugged in; scanning for a long time uses battery.

Connect the phone

  • Phone and computer must be on the same Wi-Fi.
  • On Home, scan the QR code with the phone’s camera (or type the address shown).
  • The phone warns that the connection “is not private”. That’s expected — the page comes from your own computer. Choose Advanced → Proceed. You only do this once.
  • With the slinger empty, tap Start camera and allow camera access. It measures the light for two seconds and locks it.

Scan

Press Start next to Scanner in the top bar, open Scan & Sort, then feed cards one at a time. Each card is added by itself when it’s recognised and the phone plays a sound:

Rising ping — new cardTwo low beeps — duplicate

If a card isn’t recognised within a couple of seconds the phone flashes its torch to help. Foil cards can be stubborn — reposition them to avoid glare.

Sort the stack

Keep the scanned cards in the order you fed them. In the Sorter, go card by card (Space = next) and drop each one in the set shown. Duplicates are flagged in amber; the Report lists the new cards by position so you can pull them out fast.

Wrong card? Press Wrong card — delete. Foil? Pick Holofoil or Reverse holo.

Finish the batch

When the stack is filed, press Finish batch (top bar, click twice). The batch is backed up and saved to your collection, and the scanner is ready for the next stack. Browse everything in Collection. To throw a batch away instead (a test run, or scans you want to redo), press Discard scans on Home (click twice): nothing is added to your collection, and a backup copy is still kept.

Troubleshooting

The phone page won’t open (“site can’t be reached”)

Check both devices are on the same Wi-Fi and that the camera server is running (green dot in the top bar). A firewall may be blocking it:

  • Windows: when asked “Allow Python on private networks?”, choose Allow. If you missed it, search Start for “Allow an app through Windows Firewall” and tick Python.
  • Mac: allow incoming connections for Python when macOS asks.
  • Linux with ufw: run sudo ufw allow from 192.168.0.0/16 to any port 8443 proto tcp once.
The top bar says “Waiting for phone”

The phone page is closed or the phone went to sleep. Wake it, reopen the page and tap Start camera. Use Dim screen on the phone to keep it awake without the bright display.

Red banner: “Can’t see the whole Slinger”

The phone moved or is too close. Re-centre it so the whole dark well is visible with a margin around it.

Cards aren’t being recognised
  • Make sure the card sits flat and fully inside the well.
  • Too dark or too bright? Change the lights, empty the slinger and press Relock on the phone.
  • Brand-new set? Press Check for new sets on Home.
Where is my collection stored? How do I back it up?

Everything is in the file collection.db in the TCG Catalog folder inside your Documents (Home shows the exact place, with an Open folder button). Finish batch makes a backup copy automatically, and Back up now on Home makes one any time. To move to a new computer, install the app there and copy the whole folder across.
